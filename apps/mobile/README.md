# Sonolo Mobile App

React Native + Expo + TypeScript app for voice-first Canadian English/French speaking practice.

**Status: scaffold only — no code yet.** The Expo project will be created by a tracked task (see [`../../docs/TASK_BOARD.md`](../../docs/TASK_BOARD.md)).

## Planned conventions

- TypeScript in strict mode
- Expo Router for navigation
- Voice: audio capture streamed to the backend over WebSockets
- Payments: RevenueCat · Analytics: PostHog · Errors: Sentry
